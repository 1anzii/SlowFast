SlowFast

让每一帧，按你的节奏。macOS 13+ · Apple 芯片 / Intel · 0.4.2

点击菜单栏图标呼出磁带机。主界面保留倍速、机械按键和大号 Fn 快捷键滑动开关。底部「播放器连接」舱盖可打开检查与修复，点「收起」返回磁带机；点外面或按 Esc 收起整个面板。只控制前台播放器，不扫描或控制所有后台播放源。

裸铝拉丝机身配有三个凸起金属键：SLOW 减速、RESET 恢复 1×、FAST 加速。烟色玻璃屏在等待视频时显示缓慢闪烁的 READY；读到视频后显示真实倍速，数字保持常亮。关闭快捷键显示 OFF，需要修复权限或连接时显示 CHECK。右上角设置会打开独立的圆角窗口，可拖动顶部移动；点击「完成」或按 Esc 关闭。

安装与首次使用

  1. 打开 DMG，把 SlowFast.app 拖进 Applications（应用程序），再从应用程序启动。升级前退出旧版。
  2. 点击主界面「修复权限」，在 macOS 的辅助功能列表添加并开启 SlowFast。系统验证请在本机完成。
  3. 在播放器列表点「连接 / 修复」。软件自动定位浏览器设置，或为本地播放器配置控制接口；系统和浏览器的安全确认需本人完成。
  4. 回到视频，开始播放，再按 Fn 快捷键。

分享包使用临时签名，尚未经过 Apple 公证。确认来自可信发送者后，可按 macOS 提示在「系统设置 → 隐私与安全性」中选择「仍要打开」。无需关闭系统保护。Apple 官方说明

更新后权限失效：辅助功能开关已打开却仍提示权限不足时，移除旧 SlowFast，再添加 /Applications/SlowFast.app。每台 Mac 需要独立授权，不能随安装包传递权限。

快捷键作用
Fn + ,减慢一档
Fn + .加快一档
Fn + Shift + /（Fn + ?）或 Fn + /恢复 1×

档位：0.5、0.75、1、1.25、1.5、2×；上下限不循环。部分第三方键盘不向 macOS 发送 Fn 状态，需要使用面板按钮或浏览器扩展快捷键。磁带机打开时每秒读取实际倍速和播放状态；暖橙色数码屏显示倍速，磁带转速随倍速快慢变化，视频暂停时停转。没有可读取的视频时显示 READY。关闭面板后停止轮询与绘制；开启系统「减少动态效果」时，磁带静止，READY 保持常亮。

连接状态与自动修复

先打开底部「播放器连接」检修舱，再点「全部检查」。它读取已安装播放器的真实响应，不启动未运行的播放器，也不改变倍速。绿色表示连接已验证；「尚未打开」「等待视频」是正常待机；橙色表示需要授权或修复。扩展模式不假装能读取浏览器连接状态。

点击每行「检查」重新检测；点击播放器名称展开说明。未安装的其他播放器也列在检修舱的「还支持」区域，可打开其官网。不能自动修复的步骤会显示具体原因和操作路径。

Chrome、Safari 与其他浏览器

点击「连接 / 修复」会打开随软件提供的本机检测页，用无副作用的 JavaScript 回读确认连接。首次配置会解释浏览器脚本控制权限；你同意后，软件通过可见界面定位设置。系统或 Safari 的安全提示仍由本人允许，之后自动复查。

Chrome / Edge / Brave / Vivaldi / Arc：显示（查看）→ 开发者 → 允许 Apple 事件中的 JavaScript。
Safari：设置 → 高级 → 显示网页开发者功能 → 开发者 → 允许 Apple 事件中的 JavaScript。

若之前拒绝了自动化权限，修复会打开系统自动化设置，开启对应浏览器后自动复查。只访问当前标签页的普通 HTML5 视频、开放 Shadow DOM、同源 iframe；DRM、直播、自绘播放器或网站锁定倍速可能不可控。其他 Chromium 浏览器根据同类接口适配，未逐一实机测试。

QuickTime

点击连接后允许 SlowFast 自动化控制 QuickTime。先打开并播放本地视频，再调节倍速。暂停时不会自动开始播放。能否带声音变速取决于 QuickTime 和视频格式。

IINA / mpv / VLC

自动配置本地播放器需要点击确认「配置并重启」，会暂停当前播放。配置保留备份，软件不会强制结束拒绝退出的播放器。重新打开视频后点检查；只有控制接口真实响应才显示已连接。

  • IINA：使用高级设置的 userOptions 添加 input-ipc-server。默认路径为 ~/Library/Application Support/SlowFast/iina.sock。已有接口路径会优先沿用；已有但未启用的高级选项需要你先确认，避免连带开启其他设置。旧选项备份在 SlowFast 的 Application Support 目录。
  • mpv：在 ~/.config/mpv/mpv.conf 的全局区域添加本地接口，保留配置和备份；已有接口优先沿用。命令行指定的其他配置目录需自行配置。默认独立路径为 ~/Library/Application Support/SlowFast/mpv.sock。
  • VLC：在 ~/Library/Preferences/org.videolan.vlc/vlcrc 启用 HTTP 接口，仅绑定 127.0.0.1，保留其他接口，复用或生成密码。密码保存在 VLC 配置及 macOS 钥匙串，配置和备份文件仅限当前用户读取。需要其他端口或密码时，在 SlowFast 设置中修改。

IINA / mpv 的固定接口仅适合单一播放窗口，不能保证多窗口目标。实际第三方版本未全面实机验证；协议测试不等于每个版本兼容。恢复原配置可使用相邻的 .slowfast-时间.backup 文件，IINA 可在高级设置删除新增接口并参考备份。

可选的网页兼容扩展

正常调速时无需安装。只有少数网页提示无法控制视频时才考虑使用；扩展模式的实际倍速看网页提示，磁带动画会停用。

  1. SlowFast 设置 → 高级选项 → 安装兼容扩展，把文件夹保存到固定位置。
  2. 进入 chrome://extensions（Edge 用 edge://extensions），开启开发者模式并加载该文件夹。
  3. 在 chrome://extensions/shortcuts 保留 Control+Shift+, / . / 0 三项快捷键。
  4. 开启 SlowFast 的「用扩展兼容特殊网页」，回到视频使用 Fn 快捷键。

扩展可处理获授权的跨站 iframe；系统页面、扩展商店等受限制页面不可控。无痕和本地文件访问需要另行允许。扩展不联网、不读取浏览历史、没有常驻内容脚本；它仅在接到指令时寻找视频。增强模式的真实结果看网页提示和扩展徽标。

隐私、诊断与卸载

SlowFast 完全在本机运行，不记录普通输入内容，不上传网页或视频。操作记录只保留本次运行最近 12 条播放器结果。「播放器连接」里的「全部检查」和设置中的自检可用于排错。

软件不自动设置开机启动。卸载时从菜单栏右键退出，把应用移入废纸篓。已确认写入的其他播放器配置和钥匙串密码不会随应用删除；需要恢复时使用备份或各播放器设置。
