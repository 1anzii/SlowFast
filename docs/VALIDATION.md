# 0.4.2 验证记录

日期：2026-11-12。测试结果记录本次发布范围，不表示对所有网站或播放器版本作兼容性保证。

## 自动验证范围

- 六档速度、边界、非标准初始速度、重置、Fn 物理键码和无关组合键排除。
- mpv 全局接口设置、命名分组保留、`[default]` 恢复全局及最后一个全局值生效。
- IPC 分片、异步事件过滤、request ID、回读、缺失 socket 和重复失败不泄漏文件描述符。
- VLC 本机鉴权、暂停状态、回读、错误密码。
- 真实 HTML5 视频倍速及 2× 媒体时钟；暂停不自动播放；状态只读；Shadow DOM、同源 iframe、失效目标与隐藏视频。
- MV3 扩展跨域 iframe、只调整选中视频、倍速徽标、连续命令串行、三项快捷键注册、受限网页明确失败。
- 非激活原生面板：READY 动画及倍速常亮切换，关闭动画路径常亮；磁带六档实际角速度、暂停和恢复。
- arm64 / x86_64 构建、签名完整性、资源与许可、安装包校验、干净源码独立构建与公共附件回下载校验。

## 历史硬件验证

开发机在 2026-11-10 至 2026-11-11 完成 Chrome、Safari、QuickTime 三组实体 Fn 快捷键验收，回读了播放器实际速度；Chrome 的浏览器脚本控制修复流程也完成了本机验收。0.4.2 不改动该键盘监听与浏览器控制实现。本轮不把自动键码测试描述为新的实体按键验收。

IINA / mpv / VLC 为协议模拟，未在本机安装全部第三方播放器逐版实测；Edge / Brave / Vivaldi / Arc 按同类接口适配。Safari 跨域 iframe、直播、DRM、自绘播放器和网站锁定倍速仍可能不受支持。

## 已知发布限制

独立构建初次检查发现图标工具被系统签名校验终止。构建脚本改为通过 Apple 自带 Swift 解释器直接运行图标源码，再完成完整构建和打包；没有关闭或更改系统保护。

当前无 Developer ID 公证发行，提供 ad-hoc 签名包。接收者首次运行可能需要在系统设置允许打开，并亲自授予权限；权限不能随安装包迁移。临时签名更新后可能需要移除旧辅助功能条目再添加应用。
